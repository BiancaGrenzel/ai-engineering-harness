# Context Reuse

Reuse information already available in the current session.

## Avoid redundant loading

Do not:

- Re-read unchanged files without need
- Repeat the same searches
- Restate information already present
- Load duplicate documentation

## When to reload

A fresh read or search is appropriate when:

- The file or state may have changed
- The previous result was incomplete
- Verification requires current information
- Additional detail is required to proceed correctly

## Prefer reuse over repetition

Treat earlier investigation results as working memory for the task.

Expand only what is missing.
