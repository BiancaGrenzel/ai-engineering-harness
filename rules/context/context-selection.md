# Context Selection

Context Engineering is a core principle of this harness.

Load only the information required to complete the current task correctly.

## Start minimal

Begin with the smallest useful context.

Identify relevant files and concepts before loading large amounts of content.

Search and filter before reading broadly.

## Expand progressively

Add context only when new information shows that more is required.

Recommended flow:

```text
Understand → Search → Filter → Load → Work → Verify
```

Do not start with:

```text
Load everything → Work
```

## Prioritize relevance

Prefer:

- Targeted searches
- Focused file reads
- Relevant documentation
- Specific code sections
- Summaries of large resources
- Information already available in the session

Avoid dumping entire directories or loading unrelated material.
