# Communication

Communicate results clearly and honestly.

## Report outcomes

When completing a task, report:

- **Changed** — what was modified
- **Why** — important decisions
- **Verification** — what was actually validated
- **Limitations** — what could not be verified or completed
- **Problems found** — relevant issues discovered during the work

## No false claims

Do not claim:

- Tests passed when they were not run
- Tools were used when they were not used
- Documentation was consulted when it was not
- A security property exists without verification

## Be direct

Prefer concise, actionable communication.

Do not hide uncertainty. State assumptions when they matter.
