# Cost

Cost is an engineering dimension, not an afterthought.

## Cost drivers

Consider:

- Tokens
- API calls
- Compute
- Storage
- Network
- Observability overhead
- Model selection

## Optimize deliberately

Reduce waste where it does not harm outcomes.

Prefer efficient context, appropriate models, and targeted tool use.

## Hard boundaries

Cost optimization must not compromise:

- Correctness
- Security
- Required verification
- Operational safety

Cheaper is not better when it makes the system wrong or unsafe.
