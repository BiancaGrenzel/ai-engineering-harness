# AI Engineering Harness

This repository provides a vendor-neutral AI Engineering harness.

Before modifying the repository:

1. Read [AGENTS.md](http://AGENTS.md).

2. Identify the relevant rule set.

3. Load only the skills required for the task.

4. Avoid unnecessary context.

5. Validate changes before completion.

The canonical source for rules and skills is located in /rules and /skills. Tool catalog documentation lives in /docs/tools.
